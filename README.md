# Jogo — Engenharia Reversa (versão 0.1)

Projeto escolar de estudo de mecânicas de jogos de cartas e estratégia em tempo real, implementado com HTML, CSS e JavaScript próprios.

## Como executar
1. Abra ou baixe este repositório no VS Code.
2. Instale a extensão **Live Server**.
3. Abra `index.html` e clique em **Open with Live Server**.

## Protótipo atual
- Arena com rio e pontes.
- Torres aliadas e inimigas com pontos de vida.
- Cartas com custo de elixir.
- Posicionamento de tropas, movimentação e ataques automáticos.
- IA adversária básica.
- Cronômetro, vitória/derrota e botão para reiniciar.

## Controles
Selecione uma carta e clique no seu lado da arena para posicionar a tropa.

## Estrutura
- `index.html`: interface.
- `css/style.css`: visual responsivo.
- `js/game.js`: lógica da partida e renderização.
